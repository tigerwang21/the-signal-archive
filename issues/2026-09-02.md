## Agentic Software Engineering

03 signals

01

### Agent adoption hits the mainstream: 90% weekly, 68% daily

JetBrains' survey of 15,000+ developers shows Claude Code (39%) nearly doubling GitHub Copilot (21%), with Codex up ~5x to 16% and Cursor slipping to 12%.

[JetBrains ↗](https://blog.jetbrains.com/research/2026/08/ai-coding-agent-adoption-2026/)

02

### 57% of organizations now run agents in production

LangChain's State of Agent Engineering reports quality as the top production barrier, observability near-universal at 89% versus 52% for evals, and security as the second-biggest concern.

[LangChain ↗](https://www.langchain.com/state-of-agent-engineering)

03

### Context engineering, not more intelligence, is the unlock

Agents already write 50–60% of code on some teams; structured context across the SDLC — not just a smarter model — is what lets them meet DevOps-grade precision.

[DevOps.com ↗](https://devops.com/context-engineering-is-the-key-to-unlocking-ai-agents-in-devops)

## AI Coding Security

03 signals

01

### Prompt injection graduates from theory to shipped CVEs

Amazon's Kiro IDE can be driven to exfiltrate data via a crafted workspace file, and NVIDIA's NemoClaw (CVE-2026-65105, CVSS 8.1) lets a webpage poison a local Ollama model.

[Real Hacker News ↗](https://realhacker.news/amazon-kiro-prompt-injection-can-exfiltrate-sensitive-data-through-kiro-powers)

02

### A LiteLLM supply-chain breach exposed 2,500+ organizations

A backdoored model-routing proxy, compromised via a tainted scanner container, leaked 153GB of stolen credentials and flagged 434,000 CI/CD pipelines.

[CloudSEK ↗](https://www.cloudsek.com/blog/ai-supply-chain-breach-2500-companies-434000-cicd-pipelines)

03

### Claude Code and Grok each leak via configuration injection

Claude Code's .claude/settings.json hook enables remote code execution and API-key theft, while Grok's "Cryptographic Context Injection" still exposes chat history with no patch published.

[Cyberdesserts ↗](https://blog.cyberdesserts.com/ai-agent-security-risks/)
